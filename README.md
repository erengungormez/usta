# USTA Akademi — demo

TEKNOFEST 2026 USTA programı için hazırlanan statik akademi platformu demosu.
Tüm içerik temsilîdir; derece, sertifika ve sınav sonuçları yalnızca tarayıcıda (localStorage) tutulur.

Sayfalar: Ana sayfa, Akademi (video serileri), Dersler, Doc (yazılı anlatım, şema, kod), Sınav, Sertifika, Lab, Koç, Yarışmalar.

Derleme adımı yoktur; `index.html` doğrudan açılabilir veya GitHub Pages ile yayınlanır.
